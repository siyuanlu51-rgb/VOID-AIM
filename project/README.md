# VOID//AIM — Godot 原生版

这是使用 Godot 4.7.2 制作的独立 Windows 3D 瞄准训练器，不依赖浏览器。

## 当前功能

- 原生 3D 水泥靶场、粗糙材质、工作台、灯光和阴影
- 鼠标锁定、输入限幅与平滑视角
- 灵敏度、FOV、球体尺寸、训练时长和目标颜色调整
- 物理射线命中、得分、命中率、连击和本地最佳成绩
- 右下角第一人称 Glock 18C 风格手枪模型
- 真实枪口位置火光、细曳光弹、后坐、程序化手枪声和命中确认音
- 单目标与六目标两种练枪模式，支持不限时训练
- 五轮随机变色反应速度测试与平均值结算
- 带实时预览的准星设置，可调形状、长度、粗细、中心间距、RGB 颜色和透明度
- 独立开始菜单、ESC 模糊设置菜单和 Tab 历史成绩面板
- ESC 菜单提供 0–100 主音量调节并自动保存

## 打开与导出

使用 Godot 4.7.2 打开本目录中的 `project.godot`。导出需要对应版本的 Windows 导出模板。

Windows x64 导出配置位于 `export_presets.cfg`，默认导出到仓库下的 `build/VOID-AIM.exe`。

直接运行成品时，请从 Releases 下载 `VOID-AIM-Portable-Windows-x64.zip`，解压后打开 `VOID-AIM.exe`，无需安装 Godot 编辑器。
