# VOID//AIM

一个零依赖、轻量级的 3D 瞄准训练器。通过浏览器 Canvas 实时渲染带水泥靶场、粗糙地面和工作台的透视训练场景，支持鼠标锁定瞄准、平滑视角、实时灵敏度/FOV/目标尺寸调整、计时、得分、命中率和本地最佳成绩。

右下角包含带后坐动画、枪口火光与程序化消音枪声的第一人称手枪模型，不需要下载任何图片或音频资源。

## 运行

直接双击 `index.html` 即可运行。为了获得完整的鼠标锁定体验，也可以在本目录启动任意静态服务器：

```powershell
python -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 操作

- 点击“开始训练”锁定鼠标
- 移动鼠标瞄准，左键射击
- 按 `Esc` 暂停/释放鼠标
- 所有参数和最高分保存在浏览器本地

## 体积

项目不包含第三方运行时、图片或音频资源，源码体积远低于 600 MB。若需要打包成桌面应用，建议使用系统 WebView（如 Tauri）以继续保持小体积。
